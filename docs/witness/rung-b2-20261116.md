## What was built

- `kernel/src/vectors.S` — EL1 vector table (0x800-aligned, 16 entries);
  synchronous-with-SPx → `exception_report`, IRQ-with-SPx → `irq_handler`,
  everything else → the same report, so nothing crashes silently.
- GIC-400 initialised (distributor `0xFF841000`, CPU interface
  `0xFF842000`); ARM generic timer, PPI 30, armed for **10 Hz** from
  `cntfrq_el0` — measured by hardware, not counted by frames.
- The tick counter is redrawn **from inside the IRQ handler**.
- After tick 100 (≈10 s), `kernel_main` executes `brk #0x42` on purpose.
  The sync handler masks interrupts and draws `EXCEPTION CAUGHT AND HELD`
  with ESR, ELR, and the tick count at fault — then halts. That final
  screen is the pass, photographable at leisure.
