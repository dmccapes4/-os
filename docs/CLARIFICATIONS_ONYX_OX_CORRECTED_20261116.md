- **Connascence, the general term** (Meilir Page-Jones, from the literature): two components are connascent if a change in one forces a change in the other to keep the system correct. Static forms include name, type, meaning, position, algorithm; dynamic forms include execution order, timing, value, identity. It generalises coupling: coupling says *that* components depend; connascence says *what they must agree on*. [Source: Connascence: Types, Examples, and Coupling](https://coupling.dev/posts/related-topics/connascence/) · [Source: Connascence — alchemists.io](https://alchemists.io/articles/connascence)
