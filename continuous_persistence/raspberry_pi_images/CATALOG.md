## Fit for the planned continuous process (local qwen / llama3.2 calls)

Ranked by what the photographs actually show. Model speeds are **not**
measured on these units — no tok/s figures are claimed here.

1. **Device B (Pi 5 + NVMe) — primary candidate.** The only unit with fast,
   wear-tolerant storage already seated; a continuous process that appends
   its thinking to a ledger writes constantly, and the NVMe takes that
   churn better than the microSD in IMG_1560. Gaps before continuous duty:
   no cooler is visible (sustained inference is a sustained full SoC load),
   and Pi 5 + NVMe wants the 5 V/5 A USB-C supply — no supply is pictured.
2. **Device C (cooled display Pi) — second candidate / supervisor.** The
   only actively cooled unit, and it has its own screen: suited to being
   the always-on face of the process, or the second thinker. It is
   currently waiting at an on-device setup screen with no network joined.
3. **Device A (GPi CASE 2W)** — a handheld with a safe-shutdown switch and
   a battery cover; even with a Zero 2 W fitted (none pictured) it is a
   client / terminal form factor, not a continuous thinker.
4. **Device F (Pico breakout)** — cannot run a language model; its labelled
   `RUN` / `EN` and screw-terminal GPIO suit it to be the process's
   hardware watchdog (heartbeat in, power-cycle out).
5. **Device E (e-Paper)** — a status face that holds its last image with
   power off; fits a continuous process that publishes a short status line
   per interval.
6. **Device D (3.5″ SPI LCD)** — a small local console for a Zero-class
   node; not needed by B or C.
7. **IMG_1560 microSD (64 GB)** — boot / rescue media. With the NVMe
   present, keep continuous ledger writes off this card.

Shape of the process, when built: keep the loop in a deterministic
scheduler (systemd timer or cron) that calls the model with a fixed
context file and appends the reply to an append-only ledger — the script
loops, the model only answers. That keeps a human at the gate and avoids
an LLM-planner-drives-LLM loop, which this house does not build.
